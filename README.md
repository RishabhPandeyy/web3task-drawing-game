# Quickdraw - Multiplayer Drawing & Guessing Game

A real-time multiplayer drawing and guessing game built for the Web3Task Full Stack Intern technical evaluation.

Players create or join a room, take turns drawing a chosen word, and earn points by guessing correctly.

## Live Demo

- Frontend: https://web3task-drawing-game.vercel.app
- Backend: https://web3task-drawing-game.onrender.com

## Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React, TypeScript, Vite |
| Drawing | HTML5 Canvas API |
| Backend | Node.js, Express |
| Real-time Communication | Socket.IO |
| Testing | Node.js Test Runner, Playwright |
| Deployment | Vercel and Render |

## Features

- Public and private rooms with random room codes.
- Join through a room code or invite link.
- Public-room search with a 20-second wait and cancellation.
- Player avatars, ready-up, and host-controlled game start.
- Rotating drawing turns and configurable rounds.
- Word selection, timed hints, and a drawing countdown.
- English and Hindi words, categories, and custom words.
- Normal, Hidden, and Combination word modes.
- Brush, colors, brush size, eraser, undo, and clear canvas.
- Live drawing, guesses, chat, scores, and leaderboard.
- Winner screen and Play Again.
- Host kick/ban, majority votekick, and player reports.
- Spectator mode and last-round drawing replay.
- Reconnection support with canvas restoration.
- Responsive layouts and touch drawing for phones.
